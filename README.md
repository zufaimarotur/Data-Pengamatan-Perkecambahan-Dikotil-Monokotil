# Jurnal Perkecambahan

Lembar jurnal praktikum perkecambahan (gandum & cabai) dalam satu file HTML.
Isi tabel pengamatan bisa diedit langsung dan tersimpan otomatis di browser (localStorage).

## Menjalankan
Buka `index.html` di browser, atau lihat lewat GitHub Pages.

## Deploy ke GitHub Pages
Settings → Pages → Source: `main` branch, folder `/ (root)`.
